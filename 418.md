### HTTP `418 I'M A TEAPOT`

The attempt to brew coffee with *this* teapot resulted in the error
code `418 I'm a teapot`. This page MAY be short and stout.[^1]

[^1]:
	["Hyper Text Coffee Pot Control Protocol
	(HTCPCP/1.0)"](https://www.rfc-editor.org/rfc/rfc2324#section-2.3.2) §
	*2.3.2 418 I'm a teapot*, 1998-04-01. L. Masinter. Unfortunately this web
	page does not return a real HTTP 418.
